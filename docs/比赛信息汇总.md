**CRE 是什么**：一个面向机构级智能合约的一体化编排层，特点是能接外部数据、合规、保护隐私、跨链跨系统互通。SDK 支持 **Go 和 TypeScript**。

- [ ] 展示一次**成功的模拟**（通过 CRE CLI）或在 CRE 网络上的**实际部署**

#### 官方示例方向

#### Confidential Workflows（机密工作流，可选）

### 7.2 Cardano · Agentic Commerce

**一句话**：AI agent 正在成为客户，它们会购买数据、算力、API 调用和彼此的服务。这个赛道是用 **x402** 为 Cardano 上的 agent 经济做产品。x402 是一个开放标准，让 HTTP 里保留的 402 "Payment Required" 状态码真正用于支付。

**核心流程**：agent 请求一个资源，收到报价，在链上付款，然后访问服务，全程不需要账号或 API key。x402 负责支付。Cardano 上的开放标准 **Masumi** 在支付之外补上 agent 需要的能力：托管（escrow）账户、退款、争议处理、agent 身份，以及让 agent 互相发现的链上注册表。

**三种切入方式（Pick your side of the market）**：

- **卖方**：把你的接口、API 或内容按次收费卖给 agent
- **买方**：做能为所用服务自主付款的 agent
- **中间层**：做 agent 之间的交互流程，以及围绕这些的工具和基础设施

> 官方原话：可以单独用 x402 做支付流程，也可以基于 Masumi 构建。只要能推进 Cardano 上的 agentic commerce，都在范围内。

#### 参赛条件（To Qualify）

- [ ] **在 Cardano 网络上的可运行原型**：带前端的 DApp，或者能现场演示的工具/agent
- [ ] **开源 repo**，并且有文档
- [ ] **demo 视频，最长 3 分钟**，展示产品实际运行
- [ ] **简短 write-up**：讲清问题、技术方案（用了哪些工具、框架、Cardano 基础设施），以及项目在现实中如何部署或扩展

### 7.4 NOWNodes · Multichain Infrastructure Challenge

**一句话**：基于 NOWNodes 的区块链基础设施做一个可用的 Web3 产品。NOWNodes 让你不用自己跑节点，就能通过 RPC API、WebSocket 和区块浏览器 API 连接 100 多条链，用来读链上数据、广播交易，做实时或跨链应用。

**他们想看到的**：真实的用例、有意义的链上交互，以及比赛后还能继续做下去的产品。**多链使用、扎实的技术实现、可扩展性，或对链上数据的创新使用**会获得额外加分。

#### 参赛条件（To Qualify, Teams Must）

- [ ] 注册 **NOWNodes 账号**，并在提交的项目里使用**至少一个 NOWNodes RPC/API 端点**
- [ ] 在比赛期间展示一个**可运行的产品或原型**
- [ ] 展示一个**有意义的区块链用例**，且 NOWNodes 基础设施是产品的一部分
- [ ] **清楚说明** NOWNodes 在项目架构中怎么用
- [ ] 按黑客松的提交要求提交

#### 评分标准

| 权重 | 维度 | 说明 |
| --- | --- | --- |
| **25%** | Quality and Completeness of Implementation | 做得好不好、原型完成度如何：主流程是否端到端跑通，实现是否稳定到可以演示，技术架构是否清晰连贯 |
| **25%** | Use of NOWNodes Infrastructure | NOWNodes RPC/API 集成得多实质。NOWNodes 是架构核心而不是表面集成的项目得分更高；多链使用或对链上数据的高级用法可能获得额外加分 |
| **20%** | Real-World Usefulness / Product Potential | 是否清楚地解决了真实问题、有没有可信的目标用户或用例，以及比赛后继续发展的潜力 |
| **15%** | Technical Creativity | 技术路径是否原创、有想法：可以是对链上数据、基础设施、API、多链功能的创新使用，或对现有 Web3 问题的创造性解决 |
| **15%** | Scalability and Potential for Further Development | 比赛后能否长大：架构和概念能否支持更多用户、更多网络、新功能或更广泛的实际采用 |
